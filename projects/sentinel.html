// project

sentinel

ai log detective & sre observability platform

python langgraph fastapi postgresql

// problem

when something breaks in production, digging through logs by hand to find the root cause is slow — by the time timestamps are correlated across services, the outage has already cost real downtime.

// approach

engineered a multi-agent sre observability platform using stateful langgraph workflows to automate root cause analysis. a high-concurrency ingestion engine built on python asyncio processes 100+ simultaneous telemetry feeds, and llm agents integrated via the mcp sdk map anomalous log patterns back to the exact source code location responsible — automating patch generation instead of just flagging the issue.
