// problem

equipment corrosion is expensive to catch late — by the time a fault shows up visually, the damage and the downtime that comes with it are already locked in.

// approach

built a supervised ml pipeline with scikit-learn and tensorflow to detect corrosion from sensor telemetry before failure. optimized postgresql schemas and indexed queries to handle 1tb+ of structured sensor data, plus drift-detection scripts that trigger automated retraining via cron so the model doesn't go stale over time.
